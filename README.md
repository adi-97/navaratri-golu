# Navaratri Golu Memories

A year-by-year photo gallery of our family's Navaratri Golu displays — dolls and idols arranged on steps to celebrate the nine nights of the divine feminine.

## View it

Open [index.html](index.html) directly in a browser, or serve the folder with any static file server, e.g.:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## Structure

```
index.html            entry point — page markup only
assets/
  css/style.css        styling, layout, and animations
  js/main.js           scroll-reveal, lightbox, back-to-top, background effects
  images/               gallery photos
```

No build step, package manager, or framework — plain HTML, CSS, and vanilla JS.
